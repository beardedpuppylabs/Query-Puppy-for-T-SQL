# 0.12.0 focused manual acceptance

**Manual acceptance: PASSED**

The 15 focused scenarios were accepted in the real VSCodium, Microsoft mssql, and
IntelliSenseLab environment. Validated areas include built-in Contains completion,
native and manual Signature Help, conditional and aggregate ExpectedType ranking,
aggregate presentation, window grammar and members, datepart values, built-in and
catalog-callable return/argument inference, and ordinary qualified completion.

## Required setup

The active mssql editor database must be **IntelliSenseLab**, and the existing
`qpacc` fixture must already be provisioned. The provisioning script
`manual-acceptance/extend-intellisenselab-0.11.0-fixtures.sql` ends in
`IntelliSenseLabReporting`; explicitly switch the editor connection back to
`IntelliSenseLab` before testing. After provisioning or changing databases, run
**Query Puppy for T-SQL: Refresh Schema Metadata** when cached metadata may be
stale. Do not run fixture DDL as part of this suite.

Every intentionally incomplete test is **RUN ALONE IN A FRESH SQL EDITOR**. Generic
editor `abc` suggestions are ignored and do not count as Query Puppy semantic
results. Expected candidates remain outside the SQL file so word-based suggestions
cannot create false positives.
