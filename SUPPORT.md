# Support

When reporting a problem, include:

- Improved SQL IntelliSense and VS Code versions
- Microsoft SQL Server (`ms-mssql.mssql`) version
- Whether **Show Improved SQL IntelliSense Status** reports mssql as available and connected
- The active database and the affected form of completion, without credentials or sensitive query data
- Relevant lines from **Output: Improved SQL IntelliSense** after enabling `improvedSqlIntellisense.debugLogging`
- Minimal SQL that reproduces the completion context, with confidential names replaced if necessary

This repository does not currently advertise a public issue tracker. Use the distribution channel supplied by the developer until a public support location is established. Never include passwords, tokens, or full connection strings in a report.
